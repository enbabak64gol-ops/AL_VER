# AL_VER | آل-ور — PocketBase Production

نسخه بازطراحی‌شده AL_VER برای اجرا بدون Firebase/SMS ساخته شده است.

## معماری
- PocketBase: احراز هویت، دیتابیس، فایل‌ها و API
- Railway: استقرار عمومی
- رابط RTL فارسی و responsive
- ورود با Email/Password، بدون Firebase Phone/SMS

## امکانات پیاده‌سازی‌شده
- ملک، خودرو، موتورسیکلت
- ثبت آگهی توسط کاربر با وضعیت pending
- حداکثر ۴ عکس + ۱ ویدئو
- انتشار عمومی فقط برای approved
- پنل مدیریت در `/admin.html`
- نقش‌های `user`، `admin` و `main`
- تأیید/رد آگهی توسط admin/main
- شماره تماس عمومی فقط هنگام تأیید توسط مدیریت ثبت می‌شود
- حذف دائمی آگهی فقط توسط `main`
- افزودن/حذف ادمین فقط توسط `main`
- کاربران عادی امکان ویرایش/حذف آگهی ندارند

## اولین راه‌اندازی
1. سرویس را روی Railway اجرا کنید و یک Volume دائمی روی `/pb/pb_data` بسازید.
2. پس از اولین اجرا، PocketBase Admin Dashboard را در `/_/` باز کنید.
3. یک Superuser برای خودتان بسازید.
4. در Collection `users` یک حساب کاربری بسازید یا از سایت ثبت‌نام کنید.
5. فیلد `role` آن حساب را `main` قرار دهید.
6. از `/admin.html` با همان ایمیل/رمز وارد شوید.
7. سپس مدیر اصلی می‌تواند سایر کاربران را به `admin` تبدیل کند.

## امنیت مهم
- رمز عبور یا شماره مدیر در کد عمومی قرار داده نشده است.
- برای Railway حتماً `/pb/pb_data` روی Volume دائمی باشد؛ در غیر این صورت داده‌ها با بازسازی کانتینر از بین می‌روند.
- قبل از انتشار واقعی، HTTPS دامنه Railway را فعال نگه دارید.
